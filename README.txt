MINHAS NOTAS - LANDING PAGE HTML

Esta versão utiliza apenas HTML, CSS e JavaScript.
Não precisa instalar Node.js e não precisa compilar.

COMO TESTAR
1. Extraia todos os arquivos do ZIP.
2. Abra o arquivo index.html no navegador.

COMO HOSPEDAR
Envie index.html, style.css, script.js e a pasta assets para a pasta pública da hospedagem.
Não altere a estrutura das pastas.

ARQUIVOS
- index.html: conteúdo da página
- style.css: aparência e responsividade
- script.js: animações leves e ano automático
- assets/: ícone e capturas do aplicativo

GOOGLE PLAY
Quando o aplicativo for publicado, procure por "Em breve no Google Play" no index.html
e substitua o bloco por um link para a página oficial do aplicativo.
